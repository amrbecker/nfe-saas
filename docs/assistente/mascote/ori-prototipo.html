Os nove estados

Cada estado tem um gatilho claro. Os estados de espera têm humor; os que acompanham respostas fiscais, não.

Tamanhos

O mesmo SVG em três lugares: menu aberto, menu recolhido e botão flutuante em telas de até 600 px.

Para decidir

TraçoGeométrico, coerente com o logo. Se agradar, pode ser a versão 1; se não, este arquivo vira o briefing para a arte ilustrada (ComfyUI ou Hugging Face, depois VTracer).
Camadas prontas para animarCabeça, corpo, asa, braço com a xícara, pálpebras, sobrancelhas, bico e acessórios são grupos separados com classe própria.
AcessibilidadeCom "reduzir movimento" ligado no sistema, todos os estados viram pose parada. O painel abre pelo teclado e o balão é anunciado a leitores de tela.
Conteúdo das respostasOs textos do painel são exemplos ilustrativos. As respostas reais vêm da base de conhecimento revisada pelo escritório parceiro.
